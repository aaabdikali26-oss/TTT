# TOTP генераторы мен тексерушісі

RFC 6238 бойынша уақытша 6 таңбалы код жасайтын және тексеретін Java консольдік қолданба.

## Мақсаты

Аккаунтқа кірген кезде қосымша қорғаныс ретінде әр 30 секунд сайын өзгеретін код қолданылады.
Бағдарлама кодты жасайды, жарамдылық уақытын көрсетеді және енгізілген кодтың дұрыстығын тексереді.

## Мүмкіндіктер

- RFC 6238 стандарты, HMAC-SHA1 (`javax.crypto.Mac`), 6 таңба, 30 секундтық қадам
- Құпия кілт Base32 форматында (өз Base32 іске асыруы, сыртқы кітапхана жоқ)
- Тірі көрсеткіш: код, прогресс-бар және қалған секунд (соңғы 5 секундта қызыл)
- Уақыт ауытқуы ±1 қадам шегінде есепке алынады
- Кілтті мастер-құпия сөзбен шифрлап сақтау: PBKDF2WithHmacSHA256 + AES-256-GCM (JCA)
- Әр іске қосқанда түс пен қауіпсіздік кеңесі кездейсоқ өзгереді

## Талаптар

- Java 17+
- Maven 3.8+

## Орнату және іске қосу

```bash
git clone <репозиторий-сілтемесі>
cd totp-authenticator
mvn clean package
java -jar target/totp-authenticator-1.0.0.jar
```

Windows консолінде қазақ әріптері дұрыс көрінбесе: `chcp 65001`, содан кейін қайта іске қосыңыз.

## Қолдану мысалы

```
1  Жаңа кілт жасау        -> ZHSN R2C6 YHE7 G5Y5 PHKV BOT5 XASK UN34
3  Код көрсету            -> 311 445  ████████████░░░░░░░░  18 сек
4  Кодты тексеру          -> ✔ Код дұрыс
5  ±1 қадам ауытқу        -> алдыңғы / қазіргі / келесі кодтар
```

Кілтті Google Authenticator немесе басқа қолданбаға "setup key" ретінде қолмен енгізіп,
екі жақтағы кодтардың сәйкес келетінін тексеруге болады.

## Тестілеу

```bash
mvn test
```

JUnit 5, 16 тест: RFC 6238 ресми тест-векторлары, ±1 қадам терезесі, қате формат,
Base32, кілт генерациясы, шифрлау және қате құпия сөз.

## Құрылым

```
src/main/java/kz/totp/
  Base32.java          RFC 4648 Base32
  Totp.java            TOTP генерациясы мен тексеруі
  SecretGenerator.java SecureRandom арқылы кілт жасау
  SecretVault.java     PBKDF2 + AES-GCM шифрланған сақтау
  Main.java            консольдік интерфейс
src/test/java/kz/totp/   TotpTest, Base32Test, SecretVaultTest
```

## Қауіпсіздік ескертпесі

- Құпия кілттер репозиторийде сақталмайды. Шифрланған файлдар `~/.totp-vault/` папкасына жазылады,
  `.env`, `*.key`, `*.vault` файлдары `.gitignore` ішінде.
- Код салыстыру тұрақты уақытта жүргізіледі (`MessageDigest.isEqual`), timing-шабуылдан қорғау үшін.
- Argon2 JDK құрамында жоқ, сондықтан құпия сөзден кілт шығаруға PBKDF2 (210 000 итерация) қолданылады.
- Нақты серверде бір кодты екі рет қабылдамау (replay-қорғаныс) жеке қосылуы керек.
